0.0.48

[Аккаунт]
- Добавлен круглый аватар пользователя.
- Клик по круглой иконке открывает выбор изображения.
- Изображение оптимизируется и загружается в Supabase Storage.
- URL аватара сохраняется в profiles.avatar_url.
- Добавлена кнопка удаления аватара.

[Безопасность]
- Пользователь НЕ получает обычное UPDATE-право на profiles.
- Аватар меняется только через RPC update_my_avatar().
- Поэтому клиент не может тем же запросом повысить себе role до admin.
- public_profiles содержит только id, nickname и avatar_url; e-mail туда не попадает.

[Форум]
- Аватар отображается рядом с ником автора темы.
- Аватар отображается рядом с ником автора каждого ответа.
- В форме ответа показывается пользователь, от имени которого отправится сообщение.
- Для старых сообщений с Supabase ownerId аватар подтягивается из public_profiles,
  поэтому после смены аватара он будет виден и у уже опубликованных сообщений.

[Supabase]
- supabase-schema.sql обновлён для нового проекта.
- Добавлена migration 20260808121600_profile_avatars.sql для существующего 0.0.47.
