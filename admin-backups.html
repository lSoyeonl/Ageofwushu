Резервные копии

В версии 0.0.81 код сайта хранится в GitHub, данные и авторизация — в Supabase, а новые изображения можно переводить в Yandex Object Storage без переноса старых файлов.

Проверка подключения...

1. Копия контента из админки

Скачивает JSON с site_store, профилями и реакциями. Это удобно для восстановления текстового контента, но это не полный backup Supabase Auth и не архив самих файлов Storage.

2. Восстановить контент JSON

Восстанавливает ключи контента и реакции. Зарегистрированных пользователей Auth эта кнопка не создаёт и не удаляет.

Полная база пользователей

Для восстановления пользователей вместе с их хэшами паролей используйте резервную копию базы Supabase в Dashboard. Auth хранится внутри Postgres, но браузерный publishable key не имеет права выгружать секретные поля Auth.

Открыть Database → Backups

Изображения

Старые файлы Supabase Storage продолжают работать. После подключения Yandex Object Storage новые изображения будут сохраняться там, а в Supabase останутся ссылки.

Discord уведомления о новых публикациях

Здесь настраиваются отдельные шаблоны для каждого раздела. URL вебхука по-прежнему хранится только в секрете Supabase и на сайт не попадает.

В шаблоне доступны переменные: {title} — название публикации, {section} — раздел, {url} — ссылка, {date} — дата отправки. Можно использовать Discord Markdown и любые эмодзи.
