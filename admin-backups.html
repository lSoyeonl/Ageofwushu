Резервные копии

В версии 0.0.47 код сайта хранится в GitHub, а живые пользователи, контент, реакции и изображения — в Supabase.

Проверка подключения...

1. Копия контента из админки

Скачивает JSON с site_store, профилями и реакциями. Это удобно для восстановления текстового контента, но это не полный backup Supabase Auth и не архив самих файлов Storage.

2. Восстановить контент JSON

Восстанавливает ключи контента и реакции. Зарегистрированных пользователей Auth эта кнопка не создаёт и не удаляет.

Полная база пользователей

Для восстановления пользователей вместе с их хэшами паролей используйте резервную копию базы Supabase в Dashboard. Auth хранится внутри Postgres, но браузерный publishable key не имеет права выгружать секретные поля Auth.

Открыть Database → Backups

Изображения

Database Backup не содержит сами объекты Storage — только метаданные. Поэтому важные изображения нужно резервировать отдельно из Storage.
