PATCH 0.1.16 — FIX DISAPPEARING STATS COLUMN

Причина:
- schools.html использовал organization-data-0.1.10.js;
- эта версия normalizeDetailItem не сохраняла statsText;
- при редактировании/сохранении карточки организации detailContent проходил нормализацию и поле статов удалялось;
- поэтому блок «Статы» исчезал после последующей загрузки.

Исправление:
- schools.html и school-detail.html теперь используют единый organization-data-0.1.16.js;
- statsText сохраняется при любой нормализации и повторном сохранении карточки;
- существующие заполненные статы больше не должны пропадать.

Важно: если статы уже были удалены из Supabase старой версией, их нужно заполнить один раз заново. После 0.1.16 они сохраняются.
