Установка:
1. Распакуйте ZIP.
2. Загрузите всё содержимое в корень GitHub-репозитория Ageofwushu.
3. Разрешите замену существующих файлов.
4. Новый файл buffs.html должен лежать рядом с index.html.
5. supabase-config.js в патче отсутствует — ваши ключи не затронутся.
6. SQL выполнять не нужно.
7. Edge Function Discord обновлять не нужно.
8. После GitHub Pages сделайте Ctrl+F5; на телефоне полностью закройте страницу и откройте заново.

Если номер версии хранится в kungfuSiteVersion, поменяйте его на "0.0.61".
