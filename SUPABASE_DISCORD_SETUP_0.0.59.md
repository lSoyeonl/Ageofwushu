# Discord уведомления — 0.0.59

## Что уже остается без изменений
Секрет `DISCORD_WEBHOOK_URL` уже создан в Supabase и повторно добавлять его не нужно.

## Обязательное обновление Edge Function

1. Supabase → Edge Functions → `discord-publish`.
2. Откройте вкладку **Code**.
3. Откройте `index.ts`.
4. Замените весь код содержимым файла:
   `SUPABASE_EDGE_DISCORD_PUBLISH_0.0.59.ts`
5. Нажмите **Deploy / Deploy function**.

Повторно создавать функцию не нужно.
Повторно создавать `DISCORD_WEBHOOK_URL` не нужно.
Новый SQL для версии 0.0.59 не требуется.

## Настройка шаблонов

После обновления GitHub и Edge Function:

1. Зайдите на сайт под администратором.
2. Аккаунт → Резервные копии.
3. Откройте блок **Discord уведомления о новых публикациях**.
4. Введите при желании:
   - имя отправителя;
   - URL аватара отправителя.
5. Раскройте нужный раздел и измените его шаблон.
6. Доступные переменные:
   - `{title}`
   - `{section}`
   - `{url}`
   - `{date}`
7. Нажмите **Отправить тест этого шаблона**.
8. После проверки нажмите **Сохранить все шаблоны**.

Пример:

🔥 **Новое на сайте**
Раздел: **{section}**
[{title}]({url})
Дата: {date}

## Безопасность
URL Discord webhook не сохраняется в site_store и не попадает в браузер.
Он остается только в секрете Supabase `DISCORD_WEBHOOK_URL`.
