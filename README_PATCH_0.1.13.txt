PATCH 0.1.13 — Фонари + Полезные таблицы

Основа: PRODUCTION 0.1.12_LOGIN_RLS_FIX. Поэтому полная версия 0.1.13 сохраняет исправления входа/RLS из 0.1.12.

НОВОЕ
1. «Фонари» теперь внутренний раздел сайта (lanterns.html), а не Google Sheets.
   Колонки:
   - № (автоматически)
   - НПС
   - Награда
   - Кто добавил
   Админ/модератор может добавлять, редактировать и удалять записи. Автор фиксируется при создании.

2. «Игровые Термины» на главной заменены кнопкой «Полезные таблицы».
   Новый раздел useful-tables.html:
   - оглавление сверху;
   - кнопки оглавления автоматически переносятся на новую строку;
   - неограниченное число контентов;
   - в одном контенте — несколько страниц;
   - каждая страница — отдельная таблица;
   - рабочие колонки полностью создаются/переименовываются/удаляются админом или модератором;
   - строки добавляются/редактируются/удаляются без жёсткого лимита;
   - ширина колонок изменяется перетягиванием границы заголовка.

3. Новые ключи site_store:
   - kungfuLanterns
   - kungfuUsefulTables

ВАЖНО
Для первой записи новых ключей RLS в Supabase должен разрешать INSERT/UPDATE администраторам и модераторам. В полной версии 0.1.13 уже сохранён файл SUPABASE_RLS_FIX_0.1.12.sql из предыдущего исправления.
