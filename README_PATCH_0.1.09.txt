PATCH 0.1.09 — custom detail background + content scrollbar fix

Что изменено:
1. В «Редактировать карточку» добавлена загрузка отдельного фона для страницы «Подробнее».
2. Фон сохраняется вместе с организацией и применяется только к её детальной странице.

4. Исправлен внутренний вертикальный скролл в блоках нейгунов / эффектов / навыков / приёмов / реворков.
5. Форматирование текста (цвет, размер, шрифт и т.д.) сохраняется, но опасные/мешающие layout-стили overflow и фиксированная высота удаляются при выводе.
