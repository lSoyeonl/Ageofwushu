PATCH 0.0.77 — исправление загрузки изображений в Yandex Object Storage

Исправлено:
- исправлена ошибка: преобразование data:image в Blob теперь ожидается через await;
- раньше в Supabase Edge Function уходил пустой размер файла, поэтому появлялось сообщение «Файл должен быть не больше 6 МБ» даже у небольшого изображения;
- добавлена проверка корректного размера Blob;
- в Обновлениях, Предметах и Продажах аккаунтов при ошибке Storage картинка больше не записывается как base64 прямо в базу; публикация остановится и покажет ошибку;
- cache-bust supabase-sync.js обновлён до 0.0.77.

Менять Supabase Edge Function, Secrets и CORS не требуется.
