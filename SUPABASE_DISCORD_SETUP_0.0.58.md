# Discord + профиль — настройка версии 0.0.58

## 1. GitHub
Загрузите файлы патча в корень репозитория с заменой существующих файлов. `supabase-config.js` в патче отсутствует.

## 2. Разрешить пользователю редактировать описание профиля
Supabase → SQL Editor → New query → вставить целиком `SUPABASE_PROFILE_BIO_0.0.58.sql` → Run. Выполняется один раз.

## 3. Создать Edge Function для Discord
Supabase → Edge Functions → создать функцию с именем `discord-publish`.
Вставить содержимое файла `SUPABASE_EDGE_DISCORD_PUBLISH_0.0.58.ts` как `index.ts` и Deploy.

## 4. Сохранить Discord Webhook как секрет
В настройках Edge Functions / Secrets создать секрет:

`DISCORD_WEBHOOK_URL` = полный URL вебхука из Discord.

URL вебхука не нужно и нельзя вставлять в HTML/JS сайта.

## 5. Включить уведомления
Открыть на сайте: Аккаунт → Резервные копии.
В блоке «Discord уведомления о новых публикациях»:
1. Нажать «Отправить тест».
2. Если тест пришёл в Discord — включить переключатель.
3. Нажать «Сохранить».

После этого при успешном добавлении НОВОЙ записи администратором сообщение отправляется для разделов: Обновления, О Тайвани, О Пиратке, Справочник Новичкам, Школы/Силы/Секты, Меридианы, Нейгуны, Навыки, Предметы, Артефакты, Тайники, Боты, Партнеры. Редактирование существующей записи уведомление не отправляет.
