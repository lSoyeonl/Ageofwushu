0.0.59

[Discord — шаблоны по разделам]
- В админке «Резервные копии → Discord уведомления» появился полноценный редактор шаблонов.
- Для каждого раздела свой отдельный шаблон.
- Каждый раздел можно отдельно включать/отключать.
- Для каждого шаблона доступна отдельная кнопка тестовой отправки.
- Добавлен предпросмотр текста сообщения.
- Поддерживаются переменные:
  {title}   — название новой публикации
  {section} — название раздела
  {url}     — ссылка на страницу
  {date}    — текущая дата
- Можно использовать Discord Markdown и эмодзи.
- Можно глобально менять имя и URL аватара отправителя.
- Пустые имя/аватар оставляют имя и аватар самого Discord webhook.
- Старые настройки 0.0.58 автоматически совместимы: шаблоны подставятся стандартные.
- Настройки хранятся в существующем site_store под ключом kungfuDiscordNotifications, новый SQL не нужен.

[Edge Function]
- discord-publish теперь принимает готовый шаблон сообщения от администратора.
- Поддерживает username и avatar_url.
- Все вызовы по-прежнему проверяют авторизованную сессию и роль admin.
- DISCORD_WEBHOOK_URL остается только секретом Supabase.
