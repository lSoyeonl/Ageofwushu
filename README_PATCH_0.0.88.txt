Легенды Кунг-Фу — PATCH 0.0.88

Изменения:
1. Оглавление верхнего уровня в wiki-разделах теперь редактируется администратором и модератором.
   - кнопка «Изменить разделы» в левом оглавлении;
   - можно менять название, значок и ссылку;
   - можно добавлять и удалять пункты;
   - одна настройка общая для «Новичкам», «О Тайване» и «О пиратке»;
   - данные сохраняются в Supabase site_store под ключом kungfuWikiSections.
2. Оглавление статьи из 0.0.87 сохранено: авто / вручную / не показывать.
3. В «Обновлениях» типы контента теперь можно редактировать прямо в левой панели:
   - добавление;
   - переименование (с автоматическим обновлением связанных публикаций);
   - удаление свободных типов.
4. Компактные карточки обновлений переделаны:
   - при наличии картинки левая половина карточки отдана изображению;
   - правая половина — теги, название, дата, вступление и кнопки;
   - на мобильных блоки становятся друг под другом.
5. Для администратора/модератора кнопка «Редактировать» доступна прямо в компактной карточке.

SQL менять не нужно.
Патч устанавливается поверх 0.0.87 с заменой файлов.
