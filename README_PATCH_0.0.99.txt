Легенды Кунг-Фу — PATCH 0.0.99

Что изменено:
1. Старый фон сайта заменён на новый ночной wuxia-фон с горами, пагодами, луной и туманом.
2. Новый фон подключён под отдельным именем background-night-0.0.99.webp, чтобы GitHub Pages и браузер не показывали старую картинку из кэша.
3. На главной странице в левом нижнем блоке добавлена кнопка «Игровые Термины» с переходом на опубликованную Google-таблицу.
4. Там же добавлена кнопка «Фонари» с переходом на опубликованную Google-таблицу.
5. Существующие кнопки «Мы в Вконтакте» и «Дискорд» сохранены.
6. На мобильных экранах четыре нижние кнопки автоматически переносятся в две колонки.
7. Supabase, роли Администратора/Модератора и данные разделов не изменяются.

Установка:
- загрузить содержимое PATCH поверх текущей версии 0.0.98 с заменой;
- дождаться GitHub Pages;
- при необходимости нажать Ctrl+F5.
