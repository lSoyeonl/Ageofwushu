PATCH 0.0.81 — MODERATOR

Что добавлено
- новая роль moderator;
- отдельная страница moderator-login.html;
- модератор получает те же права на управление контентом, что admin;
- в шапке, редакторах, форуме и новых публикациях роль отображается как «МОДЕРАТОР» / «Модератор»;
- вход администратора по-прежнему принимает только роль admin;
- вход модератора принимает только роль moderator;
- RLS Supabase расширяется через SUPABASE_MODERATOR_0.0.81.sql.

Установка
1. Загрузите файлы этого патча в корень сайта с заменой существующих.
2. В Supabase откройте SQL Editor и один раз выполните SUPABASE_MODERATOR_0.0.81.sql.
3. Создайте аккаунт будущего модератора обычной регистрацией на register.html.
4. В SQL Editor назначьте ему роль, заменив e-mail:

   update public.profiles
   set role='moderator'
   where email='moderator@example.com';

5. Входите через moderator-login.html по e-mail и паролю этого аккаунта.

Важно
- пароль модератора в файлах сайта не хранится; используется Supabase Auth;
- старые записи без authorRole продолжают показываться как «Админ»;
- новая публикация модератора сохраняется с authorRole='moderator' и показывается как «Модератор»;
- при редактировании старой публикации исходная подпись автора сохраняется.
