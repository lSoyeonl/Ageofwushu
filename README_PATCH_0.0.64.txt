ПАТЧ 0.0.64 — ИСПРАВЛЕНИЕ АВАТАРОВ

1. Распакуйте ZIP.
2. Загрузите ВСЕ файлы из архива прямо в корень GitHub-репозитория Ageofwushu.
3. Особенно проверьте, что рядом с index.html лежат:
   avatar-01.png ... avatar-22.png
4. Замените account.html, admin-backups.html и VERSION.txt.
5. Старую папку avatars можно не удалять.
6. SQL не нужен.
7. Discord Edge Function менять не нужно.
8. supabase-config.js в патче отсутствует.

После GitHub Pages:
- ПК: Ctrl+F5.
- Откройте страницу Аккаунт один раз: старый выбранный путь /avatars/... будет автоматически перенесён на новый URL.
