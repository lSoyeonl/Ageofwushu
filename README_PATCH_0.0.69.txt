ПАТЧ 0.0.69 — ЧЕРНОВИКИ И НОВАЯ ПАНЕЛЬ РЕДАКТОРА

Что изменено:
1. «Обновления», «О Пиратке», «О Тайване» — блок «Черновик»: сохранить / загрузить / удалить.
2. Rich-text редактор стал похож на Word.
3. Цвет текста выбирается из стандартной палитры; добавлена отдельная палитра выделения.
4. Добавлены B / I / U, размер −/+, шрифты, заголовки, ссылки, списки, выравнивание, интервалы, отступы, undo/redo.
5. Инструменты изображений и таблиц сохранены.

Установка патча поверх 0.0.68:
1. Распакуйте ZIP.
2. Загрузите все файлы из архива в корень GitHub с заменой совпадающих файлов.
3. SQL выполнять не нужно.
4. supabase-config.js менять не нужно.
5. После публикации GitHub Pages выполните Ctrl+F5.

Важно про черновики:
- ручной черновик хранится на том браузере/устройстве, где он был сохранён;
- он не публикуется и не виден посетителям;
- изображения выбранные в редакторе сохраняются вместе с ручным черновиком;
- после успешной публикации черновик удаляется автоматически.
