ПАТЧ 0.0.55 — ПАРТНЕРЫ И ОТЗЫВЫ

1. Загрузите содержимое архива в корень GitHub-репозитория.
2. Замените partners.html, admin-backups.html, VERSION.txt и supabase-schema.sql.
3. Папку supabase/migrations дополните файлом 20260808183000_partner_reviews.sql.
4. Патч НЕ содержит supabase-config.js — ваши ключи не будут затронуты.

ОБЯЗАТЕЛЬНО ДЛЯ ОТЗЫВОВ:
В Supabase → SQL Editor → New query вставьте целиком содержимое
SUPABASE_PARTNER_REVIEWS_0.0.55.sql и нажмите Run. Выполняется один раз.

После этого:
- партнеры отображаются один под другим;
- админ может закреплять записи;
- зарегистрированные пользователи могут писать отзывы со smiles;
- гости могут только читать отзывы.
