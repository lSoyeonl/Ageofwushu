Легенды Кунг-Фу — PATCH 0.0.84

Что изменено:
1. Раздел «Игровые Характеристики»:
   - добавлена закреплённая колонка «Код»;
   - у одной характеристики можно хранить несколько кодов;
   - каждый код вводится с новой строки и так же отображается в таблице;
   - колонка «Код» поддерживает изменение ширины как остальные колонки;
   - в строке показывается пометка «Админ» или «Модератор» — кто добавил запись.

2. Авторство контента:
   - новые материалы администратора и модератора сохраняют роль автора;
   - пометка «Админ» / «Модератор» выводится в основных разделах;
   - в разделах с боковыми кнопками/списками пометка также отображается рядом с названием;
   - старые материалы без сохранённой роли считаются добавленными администратором, поскольку до появления роли модератора публикация была доступна только администратору;
   - редактирование старого материала модератором не меняет исходную пометку автора.

3. Новый раздел «Сборник Квестов»:
   - название квеста;
   - награда;
   - описание;
   - поиск;
   - добавление, редактирование и удаление для администратора и модератора;
   - пометка автора «Админ» / «Модератор»;
   - данные хранятся в Supabase под ключом kungfuQuests.

4. Главная страница:
   - добавлена кнопка «Сборник Квестов»;
   - основные кнопки сделаны компактнее;
   - при 10 основных разделах кнопки располагаются по 5 в ряд на широком экране;
   - блоки выровнены по центру;
   - нижние кнопки сообщества также компактнее и центрированы;
   - мобильная адаптация сохранена.

5. Навигация:
   - ссылка «Квесты» добавлена рядом с «Характеристики» на страницах сайта.

Установка:
1. Установить поверх версии 0.0.83.
2. Скопировать файлы патча с заменой существующих.
3. Дополнительный SQL не требуется, если SQL роли модератора из версии 0.0.81 уже выполнен.
