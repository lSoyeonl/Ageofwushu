ПАТЧ 0.0.59 — РЕДАКТОР DISCORD-ШАБЛОНОВ

ГИТХАБ
1. Распакуйте ZIP.
2. Загрузите ВСЁ содержимое в корень Ageofwushu.
3. Разрешите замену HTML и supabase-sync.js.
4. supabase-config.js в патче НЕТ — ваши ключи не затронутся.

SUPABASE EDGE FUNCTION
1. Edge Functions → discord-publish → Code.
2. Откройте index.ts.
3. Замените весь код содержимым:
   SUPABASE_EDGE_DISCORD_PUBLISH_0.0.59.ts
4. Нажмите Deploy function.

ВАЖНО
- DISCORD_WEBHOOK_URL повторно создавать НЕ нужно.
- SQL в версии 0.0.59 выполнять НЕ нужно.

ПОСЛЕ УСТАНОВКИ
Сайт → Аккаунт → Резервные копии → Discord уведомления.
