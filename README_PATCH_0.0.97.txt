Легенды Кунг-Фу — PATCH 0.0.97 — ТРИ ВИДЖЕТА ОРГАНИЗАЦИЙ

Что изменено:
1. Раздел «Школы, Секты и Фракции» полностью переведён на новый общий виджет.
2. Три верхние вкладки: ШКОЛЫ / СЕКТЫ / ФРАКЦИИ.
3. Фильтры сторон: ДОБРО / НЕЙТРАЛЬНЫЕ / ЗЛО / ОСОБЫЕ.
4. Для школ добавлены 12 присланных изображений.
5. Выбранная организация показывает название, расположение, оружие и большое изображение.
6. Снизу есть карусель миниатюр и стрелки переключения.
7. Каждая организация имеет отдельную страницу school-detail.html?id=...
8. Администратор и модератор видят кнопки Добавить / Редактировать / Удалить. Обычные пользователи этих кнопок не видят.
9. На отдельной странице Администратор/Модератор может редактировать название, тип, сторону, расположение, оружие, описание, вступление и изображение.
10. Старые записи с категорией «Сила» автоматически отображаются как «Фракция».
11. Остальные страницы сайта не изменяются.

Важно:
- Секты и Фракции пока оставлены пустыми до получения изображений/данных.
- Все 12 школ пока помещены в сторону «Особые» как нейтральный черновой вариант; сторону можно изменить через редактор.
- Названия двух последних изображений пока стоят как «Школа 11» и «Школа 12» — их можно переименовать через редактор.
- Данные сохраняются через существующий ключ kungfuSchoolsForcesSects и текущий Supabase Sync сайта.
