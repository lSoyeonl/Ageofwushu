0.0.61

[Пометка «Админ»]
- В опубликованных записях разделов «Обновления», «О Пиратке», «О Тайвани» и «Боты» выводится пометка «Админ».
- В «Форуме» сохранена проверка роли автора: пометка показывается только у тем и ответов администратора.
- Новые административные записи дополнительно получают authorRole=admin.

[Новый раздел «Баффы»]
- На главной добавлена отдельная кнопка «Баффы».
- Создан buffs.html.
- Поля: Название, Другие Названия, Описание Баффа, Тип.
- Тип имеет фиксированный выбор: Бафф / Дебафф.
- На широком экране отображается 4 записи в строке.
- Адаптив: 3 → 2 → 1 карточка.
- Добавлены поиск и оглавление по Баффам/Дебаффам.
- Добавление, редактирование и удаление доступны только администратору.
- Данные сохраняются в Supabase site_store под ключом kungfuBuffs.
- Новый SQL не требуется.
- Раздел автоматически добавлен в редактор Discord-шаблонов и автоматические уведомления.

[Главная]
- Рядом с пунктом «Вход» для авторизованного пользователя появляется «Выйти из Аккаунта».
- Выход выполняется через Supabase Auth и очищает локальную сессию.
