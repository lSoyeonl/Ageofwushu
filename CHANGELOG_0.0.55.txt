0.0.55

[Партнеры]
- Исправлено сохранение/загрузка опубликованных партнеров: страница теперь напрямую ждёт Supabase getStore/saveStore, без старого localStorage-only сценария.
- Партнеры всегда отображаются одной вертикальной колонкой, один под другим.
- Администратор может закреплять и откреплять партнеров; закрепленные записи показываются первыми.
- Добавлен статус сохранения и rollback при ошибке Supabase.

[Отзывы]
- Зарегистрированные пользователи могут писать отзывы к партнерам.
- В отзывы можно вставлять 88 смайлов Age of Wushu.
- Гости могут читать отзывы, но для публикации должны войти/зарегистрироваться.
- Пользователь может удалить свой отзыв; администратор — любой отзыв.
- Отзывы обновляются через Supabase Realtime.
- Ник и аватар автора подтягиваются из public_profiles.

[Supabase]
- Добавлена таблица partner_reviews с RLS.
- Для существующего проекта выполнить SUPABASE_PARTNER_REVIEWS_0.0.55.sql один раз.
- Резервная копия из админки теперь включает partner_reviews.
