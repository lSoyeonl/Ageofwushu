Легенды Кунг-Фу — PATCH 0.0.89

Изменения:
1. Справочник новичкам
   - убраны «Тип» и «Добавить новый тип» из редактора;
   - разделы оглавления редактируются администратором/модератором через кнопку «Изменить разделы»;
   - добавлены понятные подсказки к редактору;
   - статья открывается компактно и имеет крупную кнопку «РАЗВЕРНУТЬ СТАТЬЮ».

2. Меридианы
   - добавлено полноценное оглавление;
   - администратор/модератор может прямо в оглавлении добавлять, переименовывать и удалять разделы.

3. Сборник квестов
   - неограниченное количество наград;
   - у каждой награды отдельная картинка;
   - предпросмотр перед публикацией;
   - сохранено последующее редактирование и удаление записей.

4. Предметы и Артефакты
   - метка «Админ/Модератор» перенесена с заголовка в строку тегов рядом с типом/слотом.

5. Игроки
   - увеличен текст «Добавлен»;
   - каждая карточка всегда имеет изображение;
   - если фото не выбрано, используется profile-placeholder.webp.

6. Игровые характеристики
   - заголовки колонок выровнены по центру;
   - роль автора вынесена в отдельную последнюю колонку «Роль».

7. Обновления
   - компактная карточка теперь примерно 46% изображение / 54% текст;
   - новые изображения по умолчанию показываются целиком без обрезки;
   - администратор/модератор может выбрать режим «целиком» или «заполнить рамку»;
   - при заполнении рамки можно выбрать область фокуса (9 позиций);
   - добавлен живой предпросмотр кадрирования перед публикацией.

SQL-обновление не требуется. Патч устанавливается поверх 0.0.88 с заменой файлов.
