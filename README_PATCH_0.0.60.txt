ПАТЧ 0.0.60 — ИСПРАВЛЕНИЕ АВТОМАТИЧЕСКИХ DISCORD-УВЕДОМЛЕНИЙ

1. Распакуйте ZIP.
2. Загрузите всё содержимое в КОРЕНЬ GitHub-репозитория Ageofwushu.
3. Разрешите замену существующих HTML-файлов и supabase-sync.js.
4. supabase-config.js в патче НЕТ.

После загрузки:
- подождите GitHub Pages 1–2 минуты;
- на ПК Ctrl+F5;
- на телефоне полностью закройте страницу и откройте снова;
- зайдите под админом;
- Аккаунт → Резервные копии → Discord уведомления;
- убедитесь, что автоматические уведомления включены;
- создайте НОВУЮ запись.

Редактирование старой записи уведомление не отправляет.
