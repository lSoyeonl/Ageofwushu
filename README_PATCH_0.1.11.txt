PATCH 0.1.11 — stats under icon

Изменения:
- у каждого материала добавлено поле «Статы»;
- администратор/модератор заполняет статы обычным текстом;
- на странице организации статы выводятся отдельным блоком под иконкой слева;
- справа остаётся основное форматируемое описание;
- если поле «Статы» пустое, блок не отображается;
- старый сохранённый контент совместим: отсутствие statsText не ломает карточки.
