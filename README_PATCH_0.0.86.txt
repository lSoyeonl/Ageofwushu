Легенды Кунг-Фу — PATCH 0.0.86

Wiki Reader для разделов «Справочник Новичкам», «О Тайване» и «О пиратке».

Что изменено:
- Разделы оформлены как единая база знаний: слева фиксированное оглавление, справа открытая статья.
- Добавлен быстрый переход между тремя информационными разделами прямо в боковой панели.
- Добавлен поиск по заголовку, вступлению и тексту статьи. Горячая клавиша Ctrl+K / Cmd+K ставит курсор в поиск.
- В оглавлении подсвечивается текущая статья; «Важные» материалы Тайваня/пиратки вынесены отдельной группой.
- Ссылки на статьи теперь можно копировать: используется hash-адрес, поэтому можно отправить прямую ссылку на конкретный материал.
- Добавлены «Новее / Дальше» внизу статьи.
- Если в статье есть несколько заголовков H2/H3/H4, автоматически создаётся блок «На этой странице».
- Добавлены метаданные статьи: раздел, автор, дата публикации (когда дата может быть определена по записи).
- На мобильном оглавление открывается отдельной кнопкой и превращается в выезжающую панель.
- Добавлен индикатор прогресса чтения сверху.
- Существующая Supabase-синхронизация, редакторы, изображения, таблицы, реакции и права администратора/модератора сохранены.

По мотивам функций Cửu Âm Wiki: каталог, быстрый поиск, навигация и wiki-режим чтения; визуальный стиль «Легенд Кунг-Фу» сохранён.

Установка:
Распаковать содержимое PATCH поверх версии 0.0.85 с заменой файлов.
Дополнительный SQL не требуется.
