0.0.62

[Таблицы в редакторах]
- В разделах «Обновления», «О Пиратке», «О Тайвани», «Справочник Новичкам» добавлена панель работы с таблицей.
- После выбора ячейки можно:
  + добавить строку ниже;
  + добавить колонку справа;
  + объединить выбранную ячейку с соседней слева или справа;
  + разъединить объединенную по колонкам ячейку;
  + удалить строку;
  + удалить колонку.
- Объединение сохраняется через HTML colspan и отображается после публикации.

[Восстановительный черновик]
- Добавлено автоматическое локальное сохранение введенного текста и полей административных редакторов.
- Если страница случайно перезагрузилась/закрылась, появляется блок:
  «Найден восстановительный черновик».
- Доступны кнопки «Восстановить» и «Удалить черновик».
- Черновик хранится до 7 дней.
- После успешной публикации/очистки формы черновик удаляется.
- Файлы из input type=file браузер восстановить не может; встроенные data:image из rich-text заменяются подсказкой, что изображение нужно выбрать заново.

[Баффы]
- Изображение Баффа/Дебаффа стало обязательным для новых и редактируемых записей.
- Добавлен предпросмотр изображения в форме.
- Изображение выводится в компактной карточке.
- Старые записи без изображения показывают аккуратную заглушку и при следующем редактировании требуют добавить картинку.
- Изображения сохраняются через существующую систему Supabase Storage.

[Профиль]
- Добавлен выбор из 22 готовых иконок из предоставленного пользователем архива avatar.rar.
- Добавлена отдельная кнопка «Загрузить своё изображение».
- Выбранная готовая иконка сохраняется как avatar_url и отображается на форуме/в профиле так же, как пользовательская аватарка.
- Кнопка удаления аватара сохранена.

[Supabase]
- Новые таблицы/колонки не требуются.
- SQL для 0.0.62 выполнять не нужно.
- Discord Edge Function менять не нужно.
