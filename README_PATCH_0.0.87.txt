Легенды Кунг-Фу — PATCH 0.0.87

Управляемое оглавление + компактные обновления + исправление горизонтального переполнения.

Что изменено:
- В «Справочник Новичкам», «О Тайване» и «О пиратке» администратор и модератор могут управлять оглавлением каждой статьи.
- Для статьи доступны три режима блока «На этой странице»: автоматически, вручную, не показывать.
- В ручном режиме пункты вводятся по одному на строку: их можно добавлять, удалять и менять местами.
- Добавлен переключатель «Показывать материал в левом оглавлении». Скрытый материал не виден обычным пользователям в меню, но администратор/модератор видит его с пометкой «Скрыто из оглавления» и может вернуть обратно.
- Старые материалы совместимы: если новые настройки не заданы, используется прежний автоматический режим и материал показывается в оглавлении.
- Раздел «Обновления» теперь по умолчанию показывает компактные карточки. Одновременно разворачивается только выбранная запись.
- Компактная карточка обновления уменьшена: миниатюра, заголовок, дата и короткое вступление; реакции и административные кнопки не занимают место до раскрытия.
- Исправлено горизонтальное переполнение длинного текста, ссылок, pre/code, изображений и таблиц. Исправление действует во всех разделах, использующих общий rich-output.
- Таблицы при необходимости прокручиваются внутри материала, а не растягивают всю страницу.

SQL обновлять не требуется.

Установка:
Распаковать PATCH поверх версии 0.0.86 с заменой файлов.
