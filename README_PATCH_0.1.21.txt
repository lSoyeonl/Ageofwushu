PATCH 0.1.21 — компактная главная

Изменения:
- основные разделы на широких экранах собраны в две центрированные строки;
- карточки уменьшены по высоте, иконки и отступы компактнее;
- поиск и заголовок занимают меньше вертикального места;
- нижние карточки сообщества на широких экранах помещаются в одну строку;
- социальные кнопки и блок благодарности уменьшены;
- мобильная раскладка сохранена.
