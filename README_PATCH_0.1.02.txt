KungFu Legends PATCH 0.1.02 — STRUCTURED ORGANIZATION CONTENT

Изменения раздела «Школы, Секты и Фракции»:

1. Кнопка/раздел «Контент» на витрине удалён.
   На карточке остаются «Подробнее» и, для администратора/модератора, «Редактировать карточку».

2. На странице каждой организации все материалы показываются сразу одной вертикальной лентой, без вкладок:
   - Нейгуны
   - Специальные эффекты
   - Специальные навыки
   - Приёмы
   - Реворки приёмов

3. Администратор и модератор могут прямо в каждом разделе нажимать «Добавить».
   Каждый материал содержит:
   - название;
   - основное изображение;
   - форматируемое описание.

4. Описание использует редактор как в «Обновлениях»:
   цвет текста, размер, шрифт, жирный/курсив, списки, ссылки, таблицы и дополнительные изображения внутри описания.

5. Специальные эффекты, специальные навыки, приёмы и реворки — без ограничения количества.

6. Для нейгунов сохранены ранее заданные лимиты:
   - Школа: до 6;
   - Секта: до 2;
   - Фракция: до 1.

7. Все элементы расположены вертикально: один материал под другим. Внутри элемента сначала заголовок, затем изображение, затем описание.

8. Сохранение использует существующий механизм организаций и Supabase store, если Supabase настроен.
