ПАТЧ 0.0.68 — ВСТУПЛЕНИЕ К СТАТЬЯМ

Изменены разделы:
- Справочник Новичкам
- Обновления
- О Пиратке
- О Тайвани

Что появилось:
- поле «Вступление» до 1200 символов;
- длинные статьи показывают вступление рядом с первой картинкой;
- полный rich-text открывается по кнопке;
- старые записи без вступления больше не показывают некрасивый автоматически склеенный текст.

Установка:
1. Распакуйте ZIP.
2. Загрузите файлы в корень GitHub с заменой.
3. supabase-config.js в патче отсутствует.
4. SQL выполнять не нужно.
5. Discord Edge Function менять не нужно.
6. После публикации GitHub Pages сделайте Ctrl+F5.

Для уже опубликованной старой статьи:
Редактировать → заполнить «Вступление» → Сохранить изменения.
