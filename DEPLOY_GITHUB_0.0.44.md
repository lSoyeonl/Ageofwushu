# Легенды Кунг-Фу 0.0.44 — подготовка к GitHub Pages

## Обязательный шаг перед полноценной публикацией

Сайт уже может открываться на GitHub Pages, но для **единого аккаунта на телефоне и компьютере**, общей базы контента и общего форума необходимо подключить ваш проект Supabase.

Откройте `supabase-config.js` и замените три значения:

```js
window.KF_SUPABASE_CONFIG = {
  url: "https://ВАШ_PROJECT_ID.supabase.co",
  anonKey: "ВАШ_PUBLISHABLE_ИЛИ_ANON_KEY",
  adminEmail: "EMAIL_АДМИНИСТРАТОРА",
  storageBucket: "site-images"
};
```

`service_role` key сюда вставлять нельзя.

## Настройка базы

1. Откройте Supabase → SQL Editor.
2. Выполните целиком `supabase-schema.sql`.
3. Создайте пользователя администратора через Supabase Authentication.
4. Назначьте ему роль:

```sql
update public.profiles
set role='admin'
where email='ВАШ_EMAIL_АДМИНИСТРАТОРА';
```

5. В Authentication → URL Configuration добавьте URL вашего GitHub Pages сайта и разрешённый redirect на `account.html`.

## Что произойдёт, если Supabase пока не заполнен

Регистрация и вход не падают с технической ошибкой. Сайт включает резервный локальный режим:
- аккаунт работает только в текущем браузере;
- форум/объявления используют IndexedDB и не упираются в маленькую квоту `localStorage`;
- общий аккаунт между телефоном и компьютером появится только после подключения Supabase.

## Перед загрузкой на GitHub

Загрузите содержимое папки/архива в корень репозитория. `.nojekyll` уже включён.
После обновления версии сделайте Ctrl+F5, чтобы браузер не использовал старые JS/CSS.
