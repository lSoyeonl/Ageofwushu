PATCH 0.1.12 — LOGIN / RLS FIX

Причина ошибки:
"new row violates row-level security policy for table site_store" означает,
что браузер попытался записать строку в Supabase site_store, но RLS-политика
не разрешила эту операцию.

Что изменено во фронтенде:
1. Обычный игрок больше не пытается фоново публиковать staff-контент в site_store.
   Локальные UI-инициализации не вызывают всплывающую RLS-ошибку.
2. Обычному игроку разрешены только пользовательские общие ключи:
   - kungfuForumTopics
   - kungfuPlayers
3. Вход игрока не считается неуспешным только из-за временной ошибки чтения profiles:
   после успешного Supabase Auth создаётся безопасный локальный профиль роли user.
4. Аналогичный fallback добавлен для getCurrentProfile и регистрации.
5. Версия supabase-sync обновлена до 0.0.85, ссылки в HTML получили cache-bust ?v=0.0.85.

ОБЯЗАТЕЛЬНО:
После загрузки файлов выполните SUPABASE_RLS_FIX_0.1.12.sql в Supabase -> SQL Editor.
Без SQL база всё равно может отклонять INSERT/UPDATE из-за старых RLS-политик.

После установки:
- обновить сайт с Ctrl+F5;
- проверить вход обычным аккаунтом;
- проверить переход на Google Sheets;
- проверить добавление темы на форуме;
- проверить вход администратора/модератора и редактирование контента.
