PATCH 0.1.04 — рамки и центрирование изображения

Исправлено по макету:
1. Верхний блок фильтров и блок карточки организации теперь имеют отдельные рамки и промежуток между ними.
2. Убрано ощущение пересечения рамок по краям.
3. Высота блока организации уменьшена — пустого места справа стало значительно меньше.
4. Большое изображение организации теперь автоматически центрируется по горизонтали и вертикали.
5. Изображение больше не прижимается к правому нижнему краю.
6. Миниатюры и превью изображений центрируются.
7. Адаптивное поведение сохранено для планшета и телефона.
