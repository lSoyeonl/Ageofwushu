Легенды Кунг-Фу — PATCH 0.0.82 GAME STATS

Добавлено:
- Новый раздел game-stats.html «Игровые Характеристики».
- Обязательные поля: русское, английское и китайское название.
- Необязательное описание для каждой характеристики.
- Большая адаптивная таблица с поиском по всем полям.
- Администратор и модератор могут добавлять, редактировать и удалять строки.
- Администратор и модератор могут добавлять, переименовывать и удалять дополнительные колонки.
- Ссылка «Характеристики» добавлена в навигацию и карточка раздела — на главную страницу.
- Данные сохраняются в Supabase site_store под ключом kungfuGameStats.

ВАЖНО:
Этот патч рассчитан на установленный 0.0.81 MODERATOR. Дополнительный SQL для 0.0.82 не требуется: права модератора на site_store уже обеспечиваются SQL-патчем 0.0.81.
