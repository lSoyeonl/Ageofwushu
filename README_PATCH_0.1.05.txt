PATCH 0.1.05 — UNIVERSAL ORGANIZATION SCENE

Что изменено:
1. Правая область карточки школы/секты/фракции переделана в универсальную «сцену» для арта.
2. Основное изображение всегда центрируется и показывается целиком через object-fit: contain.
3. За основным изображением автоматически создаётся мягкий атмосферный фон из того же арта (blur + затемнение), чтобы не было ощущения пустого прямоугольника.
4. Добавлена виньетка и очень мягкое растворение нижнего края — если исходная картинка уже обрезана снизу, срез выглядит естественнее.
5. Сцена адаптируется под разные пропорции изображений школ, сект и фракций.
6. На мобильных размеры сцены автоматически уменьшаются без обрезки изображения.
7. Сохранены все функции версии 0.1.04: особенности, редактирование карточки, структурированный контент и центрирование превью.

Установка: распаковать PATCH поверх версии 0.1.04 с заменой файлов.
