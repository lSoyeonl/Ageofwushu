kungfu_legends_PATCH_0.1.01_RICH_ORG_CONTENT

Переделка раздела «Школы / Секты / Фракции» после версии 0.1.00.

Главное изменение:
Подробный контент организации больше не собирается из отдельных жёстких карточек «нейгун / реворк / изображение».
Теперь администратор и модератор редактируют одну полноценную статью — по тому же принципу, что в разделе «Обновления».

В редакторе доступны:
- заголовки и обычный текст;
- разный цвет текста;
- шрифты и размеры;
- жирный / курсив / подчёркивание / зачёркивание;
- выравнивание;
- списки;
- таблицы;
- изображения прямо внутри текста;
- несколько изображений;
- размер изображения;
- обтекание / блочное положение / поверх / за текстом;
- шаблон расположения материала «как на примере».

Для удобства шаблон учитывает структуру:
- школа: 6 нейгунов и 7 реворков;
- секта: 2 нейгуна;
- фракция: 1 нейгун.
Это не отдельные жёсткие формы — админ/модератор сам оформляет материал и картинки внутри статьи.

Витрина:
- отдельная иконка карточки остаётся независимой от большого изображения;
- кнопка «Контент» ведёт сразу в редактор подробной страницы.

Сохранение:
- при настроенном Supabase данные сохраняются через общий site_store и изображения из редактора загружаются через существующий механизм Supabase Storage;
- локальное сохранение остаётся резервным режимом.

Лазурная Стража:
- добавлена демонстрационная страница в компоновке, близкой к предоставленному примеру:
  3 колонки сверху (условия / карта / титулы), далее крупные секции изображений — предметы, реворки, приёмы, спец. скиллы, костюмы, нейгун.
